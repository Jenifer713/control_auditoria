# Auditoría COBIT 2019 — Papeles de Trabajo

Herramienta HTML interactiva para auditorías de gobierno y gestión de I&T basada en **COBIT 2019**.

## Contenido

| Archivo | Descripción |
|---|---|
| `auditoria_cobit2019_completo.html` | Versión completa con formularios individuales para los **40 objetivos** de los 5 dominios (EDM, APO, BAI, DSS, MEA) |
| `deepseek_html_20261118_75ce8d.html` | Versión original con tablas transversales |
| `bases_informacion_formateadas.xlsx` | Base de información de referencia |

## Características

- 5 dominios COBIT 2019: EDM, APO, BAI, DSS, MEA
- 40 formularios individuales de evaluación por objetivo
- Criterios de evaluación específicos por proceso
- Niveles de capacidad 0–5
- Exportación a Excel con estilos
- Barra de progreso global
- Semáforo de hallazgos y plan de acción

## Uso

Abrir `auditoria_cobit2019_completo.html` directamente en el navegador. No requiere servidor.
